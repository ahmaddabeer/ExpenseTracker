# 💰 Expense Tracker – Android App

A simple and user-friendly Android application to manage and track daily expenses. Users can add, view, edit, and delete their expense records while keeping track of their spending.

Built using **Kotlin and Jetpack Compose**, following modern Android development practices and MVVM architecture.

## ✨ Features

- **Expense Management:** Add and manage daily expenses.
- **View Expenses:** View all recorded expenses in one place.
- **Expense Details:** View detailed information about individual expenses.
- **Edit Expenses:** Update existing expense records.
- **Delete Expenses:** Remove unwanted expense records.
- **Local Storage:** Store expense data locally using Room Database.
- **Modern UI:** Clean and intuitive interface using Material 3.
- **Navigation:** Navigate between different app screens easily.

## 🏗️ Architecture

The application follows **MVVM (Model-View-ViewModel)** architecture to maintain separation of concerns and make the code more organized and maintainable.

- **Presentation Layer:** Jetpack Compose UI and ViewModels.
- **Data Layer:** Room Database, DAO and Repository.
- **Dependency Injection:** Dagger Hilt.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Clone the Repository

```bash
git clone https://github.com/ahmaddabeer/ExpenseTracker
```

### Open the Project

1. Open Android Studio.
2. Select **Open** and choose the cloned project.
3. Wait for Gradle synchronization to complete.
4. Run the application on an emulator or Android device.
