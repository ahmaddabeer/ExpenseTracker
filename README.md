# 💰 Expense Tracker – Android App

A simple and user-friendly Android application to manage and track your daily expenses. The app allows users to view their expenses, edit existing records, and delete expenses with ease.

Built using **Kotlin and Jetpack Compose**, following modern Android development practices.

## ✨ Features

- **View Expenses:** View your recorded expenses in one place.
- **Expense Details:** View detailed information about each expense.
- **Edit Expenses:** Update existing expense details.
- **Delete Expenses:** Remove expenses you no longer need.
- **Local Storage:** Store expense records locally using Room Database.
- **Modern UI:** Clean and intuitive interface built with Material 3.
- **Navigation:** Navigate between different app screens easily.

## 🏗️ Architecture

The application follows the **MVVM (Model-View-ViewModel)** architecture to keep the code organized and maintainable.

- **Presentation:** Jetpack Compose UI and ViewModels
- **Data:** Room Database, DAO and Repository
- **Dependency Injection:** Dagger Hilt

## 🎯 Project Goal

The goal of this project is to build a simple and practical expense tracking application while learning and implementing modern Android development technologies and architecture.
